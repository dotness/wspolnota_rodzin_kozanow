# Manage News Skill

This skill provides step-by-step instructions and automated CLI tools to manage news articles and announcements on the Wspólnota Rodzin website.

## Overview

- **Source of Truth**: `data/content.json` (`news` array)
- **Offline Sync**: `js/content-data.js` (auto-regenerated by CLI scripts)
- **Images Directory**: `assets/news/<article_id>/`
- **PDF Documents Directory**: `assets/docs/`
- **Automation CLI**: `scripts/manage_news.py`

---

## Workflows

### 1. List Existing News Articles

To inspect existing articles, their IDs, publication dates, and slugs:

```bash
python3 scripts/manage_news.py list
```

To get structured JSON output:

```bash
python3 scripts/manage_news.py list --json
```

---

### 2. Add a New News Article

Run `scripts/manage_news.py add` with the desired parameters:

```bash
python3 scripts/manage_news.py add \
  --title "Tytuł nowego artykułu" \
  --date "2026-09-25" \
  --content "Treść artykułu lub znacznik HTML..." \
  --image "/path/to/local/image.jpg"
```

#### Parameters:
- `--title` (Required): The Polish title of the article.
- `--date` (Optional): Publication date in `YYYY-MM-DD` format (defaults to today).
- `--content` (Optional): Body text or HTML. Paragraphs `<p>` are wrapped automatically if raw text is provided.
- `--content-file` (Optional): Path to a text or HTML file containing the article body.
- `--excerpt` (Optional): Short 1-2 sentence preview. If omitted, it is automatically derived from the content.
- `--image` (Optional): Path to an image file. The script will automatically copy it into `assets/news/<new_id>/` and link it as `featuredImage`.
- `--attachment` (Optional, repeatable): Path to a PDF document. The script will copy it to `assets/docs/` and register it in `attachments`.
- `--slug` (Optional): URL-safe slug. If omitted, it is automatically transliterated from the title.
- `--author` (Optional): Defaults to `"Wspólnota Rodzin"`.

The script automatically:
1. Generates a unique numeric ID.
2. Formats and inserts the article at the top of `data/content.json`.
3. Runs `scripts/export_js_data.py` to keep `js/content-data.js` in sync.
4. Runs `scripts/validate_content.py` to guarantee schema correctness.

---

### 3. Update an Existing News Article

To modify any fields of an existing article by ID or slug:

```bash
python3 scripts/manage_news.py update \
  --id 19372 \
  --title "Zaktualizowany tytuł" \
  --content "<p>Nowa treść artykułu...</p>"
```

#### Supported Update Flags:
- `--id` (Required): ID or slug of the article to update.
- `--title`: Updated title.
- `--date`: Updated date (`YYYY-MM-DD`).
- `--excerpt`: Updated excerpt.
- `--content`: Updated inline content.
- `--content-file`: Path to file with updated content.
- `--image`: Path to new featured image (will be copied into the article's asset folder).
- `--clear-image`: Clears the featured image.
- `--attachment`: Adds attachment file to `assets/docs/`.

---

### 4. Remove a News Article

To delete an article:

```bash
python3 scripts/manage_news.py remove --id 19372
```

To also delete its image directory under `assets/news/<id>/`:

```bash
python3 scripts/manage_news.py remove --id 19372 --delete-assets
```

---

## Verification & Deployment

After adding, updating, or removing news content:

1. **Verify Schema**:
   ```bash
   python3 scripts/validate_content.py
   ```
2. **Verify Asset Files**:
   ```bash
   python3 scripts/verify_assets.py
   ```
3. **Verify in Browser**:
   Open `index.html` locally or inspect via local HTTP server (`python3 -m http.server 8000`).
4. **Publish**:
   - For preview environment: `git push origin preview` (deploys to `preview.wspolnotarodzin.pl`).
   - For production: merge to `main` and `git push origin main` (deploys to `wspolnotarodzin.pl`).
