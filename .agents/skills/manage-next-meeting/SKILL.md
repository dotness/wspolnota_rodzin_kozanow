# Manage Next Meeting Skill

This skill provides step-by-step instructions and automated CLI tools to manage the "Najbliższe Spotkanie Wspólnoty" (Next Community Meeting) section on the Wspólnota Rodzin website.

## Overview

- **Location on Page**: Positioned directly underneath the top headline banner (`headline-poster-card`).
- **Visual Behavior**:
  - Displays a warm card with date, location, and an interactive meeting poster thumbnail.
  - Clicking the image preview opens a full modal containing the poster and meeting agenda (`contentHtml`).
  - If no meeting is scheduled (`nextMeeting: null`), the card is automatically hidden.
- **Source of Truth**: `data/content.json` (`siteConfig.nextMeeting`)
- **Offline Sync**: `js/content-data.js` (auto-regenerated by CLI scripts)
- **Meeting Images Directory**: `assets/images/meeting/`
- **Automation CLI**: `scripts/manage_meeting.py`

---

## Workflows

### 1. View Current Meeting Notice

To inspect the currently scheduled meeting information:

```bash
python3 scripts/manage_meeting.py show
```

Output displays:
- Title
- Date & time
- Location
- Poster image path
- Short description
- Modal HTML status

---

### 2. Update Next Meeting Notice

To update date, location, poster image, or meeting details:

```bash
python3 scripts/manage_meeting.py update \
  --title "Spotkanie u św. Jadwigi – Wspólnota Rodzin" \
  --date "Niedziela, 27 września 2026 r., po Mszy św. o godz. 10:30" \
  --location "Salka parafialna pod kościołem św. Jadwigi" \
  --image "/path/to/poster.jpg" \
  --description "Serdecznie zapraszamy wszystkie rodziny na spotkanie i warsztaty." \
  --content "<h4>W programie:</h4><ul><li>Modlitwa</li><li>Katecheza</li><li>Poczęstunek</li></ul>"
```

#### Parameters:
- `--date` (Required if configuring a new meeting): Human-readable date and time text.
- `--title` (Optional): Custom meeting title (defaults to `"Spotkanie u św. Jadwigi – Wspólnota Rodzin"`).
- `--location` (Optional): Meeting venue (defaults to `"Salka parafialna pod kościołem św. Jadwigi"`).
- `--image` (Optional): Path to poster image file. The script copies it into `assets/images/meeting/` and updates the link.
- `--clear-image` (Optional flag): Removes the poster image.
- `--description` (Optional): Short teaser text.
- `--content` (Optional): HTML or text formatted details displayed inside the popup modal when clicked.
- `--content-file` (Optional): Path to file with HTML modal content.

The script automatically:
1. Updates `data/content.json` (`siteConfig.nextMeeting`).
2. Runs `scripts/export_js_data.py` to regenerate `js/content-data.js`.
3. Runs `scripts/validate_content.py` to verify data integrity.

---

### 3. Remove / Hide Next Meeting Notice

When a meeting has passed and no new meeting is yet announced:

```bash
python3 scripts/manage_meeting.py remove
```

This sets `siteConfig.nextMeeting = null`. On the website, the `#meeting-card` container is cleanly hidden (`display: none`), leaving no empty boxes or broken layout.

---

## Verification & Deployment

After updating or removing meeting info:

1. **Verify Schema**:
   ```bash
   python3 scripts/validate_content.py
   ```
2. **Verify Assets**:
   ```bash
   python3 scripts/verify_assets.py
   ```
3. **Verify in Browser**:
   Open `index.html` locally or inspect via local HTTP server (`python3 -m http.server 8000`).
4. **Publish**:
   - For preview environment: `git push origin preview` (deploys to `preview.wspolnotarodzin.pl`).
   - For production: merge to `main` and `git push origin main` (deploys to `wspolnotarodzin.pl`).
